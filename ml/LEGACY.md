# Legacy ML components

These parts are kept for reference and experiments, but are NOT the default path for restart:

- `ml/scripts/*`
- `ml/src/*`
- `ml/models/release_demo_v1/*`
- `ml/models/trained_models/*`

Use `ml/minimal/*` as the primary learning and development path.

Why kept:
- historical experiments
- previous model artifacts
- useful utilities for future scaling

Do not delete legacy files now. Archive first, then remove later only after minimal pipeline is stable.
